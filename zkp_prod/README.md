# Production ZKP System

**Status**: Production-Ready Cryptographic ZKP System  
**Circuit**: Range Commitment Proof (Groth16 SNARK)  
**Version**: v1.0.0

---

## 🎯 **Overview**

This directory contains a **production-grade Zero-Knowledge Proof system** that replaces the thesis's abstracted ZKP oracle with real cryptographic SNARKs.

### **What It Proves**
- **Range**: Secret value `x` is within [0, 1,000,000]
- **Commitment**: Binds `x` to specific execution context
- **Zero-Knowledge**: Reveals nothing about `x` except it's in range

### **Security Properties**
- ✅ **Cryptographic Soundness**: Cannot forge proofs for invalid `x`
- ✅ **Anti-Replay**: Context binding prevents proof reuse
- ✅ **Witness Protection**: `x` and `salt` never logged/persisted
- ✅ **On-Chain Verification**: Solidity verifier contract

## 🚀 **Quick Start**

### **1. Install Dependencies**
```bash
cd /home/ubuntu/Projects/THESIS/fhe_smart_contract
./zkp_prod/scripts/setup.sh
```

**What this installs**:
- **Local Dependencies** (in `zkp_prod/node_modules/`):
  - `circomlib` v2.0.5 (pinned)
  - `snarkjs` v0.7.0 (pinned)
- **Global Tools**:
  - `circom` v2.x (compiler)
- **Trusted Setup**:
  - Powers of Tau (Phase 1)

**Time**: ~5 minutes

### **2. Build Circuit**
```bash
./zkp_prod/scripts/build.sh
```

**What this generates**:
- `artifacts/range_commit_0001.zkey` (proving key)
- `artifacts/verification_key.json` (verification key)
- `artifacts/range_commit.wasm` (witness generator)
- `contracts/Verifier.sol` (Solidity verifier)

**Time**: ~2-3 minutes

### **3. Generate Proof (Python)**
```python
from zkp_prod.python.zkp_prover import ProductionZKPProver

prover = ProductionZKPProver()

proof_data = prover.generate_proof(
    x=500000,                    # Secret value (0-1,000,000)
    chain_id=11155111,           # Sepolia testnet
    contract_address=b'...',     # Contract address (20 bytes)
    operation_type=0,            # 0=validate, 1=compute, 2=decrypt
    request_id=b'...'           # Unique request ID (32 bytes)
)

# proof_data contains:
# - proof: Groth16 SNARK proof
# - publicSignals: [commitment, contextHash]
# - commitment: Poseidon(x, salt, contextHash)
# - contextHash: Poseidon(chainId, addr, opType, reqId)
```

### **4. Verify On-Chain (Solidity)**
```solidity
// Deploy Verifier.sol
Verifier verifier = new Verifier();

// Verify proof
bool isValid = verifier.verifyProof(
    proof.a,
    proof.b,
    proof.c,
    [commitment, contextHash]
);

require(isValid, "ZKP verification failed");
```

## 🔒 **Security Model**

### **Trusted Setup**
- **Phase 1**: Hermez Powers of Tau (perpetual ceremony)
- **Phase 2**: Local entropy contribution (this machine)
- **Caveat**: Groth16 requires trusted setup (see docs/SECURITY.md)

### **Adversary Protection**
| Attack | Protection |
|--------|-----------|
| Invalid range proof | Cryptographic soundness (Groth16) |
| Replay attack | Context binding (chainId, requestId) |
| Cross-contract misuse | Context binding (contractAddr) |
| Witness leakage | Sanitizer + temp file deletion |
| Proof substitution | Commitment binding to context |

### **What's NOT Protected**
- Trusted setup compromise (requires SNARK upgrade to PLONK/Halo2)
- Side-channel attacks (requires constant-time implementations)
- See `docs/SECURITY.md` for complete threat model

## 🆘 **Troubleshooting**

### **Build fails**
```bash
# Check Node.js version (>= 18 required)
node -v

# Reinstall dependencies
./zkp_prod/scripts/setup.sh
```

### **Proof generation fails**
```bash
# Check artifacts exist
ls zkp_prod/artifacts/range_commit_0001.zkey

# Rebuild if missing
./zkp_prod/scripts/build.sh
```

### **On-chain verification fails**
- Check public signals match (commitment, contextHash)
- Verify Verifier.sol deployed correctly
- Check gas limits (verification ~300K gas)
