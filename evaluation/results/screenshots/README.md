## Usage

These screenshots can be used in your thesis document to demonstrate:
- The complete workflow of the privacy-preserving smart contract system
- User interface design and user experience
- Step-by-step demonstration of FHE, ZKP, and blockchain integration
- Visual representation of encrypted computations
- Blockchain transaction traceability

## Technical Details

- Screenshots taken at 1920x1080 resolution
- Full-page screenshots to capture complete interface
- All screenshots show the local blockchain simulator mode
- Timestamps and transaction hashes are visible for verification
